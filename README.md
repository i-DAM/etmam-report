# Etmam Report Analyzer

A Streamlit-based application for analyzing municipal daily reports and automatically generating Excel and PowerPoint summaries.

## Features

- Upload and analyze daily report files
- Automated Excel report generation
- Automated PowerPoint generation
- Streamlit interactive interface
- Organized report processing workflow

## Technologies Used

- Python
- Streamlit
- Pandas
- OpenPyXL
- python-pptx

## Project Structure

```bash
assets/          # Images and assets
templates/       # PowerPoint templates
analysis.py      # Data analysis logic
ppt_fill.py      # PowerPoint automation
app.py           # Streamlit application
```

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## Notes

This project was developed as part of practical AI and automation work for municipal report analysis.
